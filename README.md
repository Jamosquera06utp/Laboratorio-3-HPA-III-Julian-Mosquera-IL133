# Laboratorio 3 - HPA III

Repositorio para la entrega de los proyectos y prácticas correspondientes al Laboratorio 3 de Herramientas de Programación Aplicada III (Universidad Tecnológica de Panamá).

## Contenido del Repositorio

* **`Lab3_AppEmpresas`**: Aplicación de Windows Forms enfocada en la gestión de colaboradores con validaciones de datos (`ErrorProvider`, `Regex`), utilidades estáticas y visualización de registros mediante `DataGridView`.
* **`Lab3_Craps`**: Implementación en consola de la lógica del juego de dados Craps, utilizando enumeraciones (`enum`), estructuras de control y generación de números aleatorios.
* **`Practica_ToolStrip`**: Ejercicio práctico enfocado en el diseño e integración de barras de herramientas (`ToolStrip`) y navegación en interfaces de escritorio.
